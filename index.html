Penyimpanan Database Cloud (Supabase)

Hubungkan ke database cloud PostgreSQL Supabase untuk sinkronisasi data antar-divisi dan cabang secara online & real-time.

Kredensial API Supabase

Ditemukan di Supabase Dashboard -> Project Settings -> API -> Project URL
Ditemukan di Supabase Dashboard -> Project Settings -> API -> Project API Keys (anon public)
Push Data Lokal -> Cloud

Kirim semua data aset, ruangan, kategori, dan divisi dari browser ini ke database Supabase Cloud.

Tarik Data Cloud -> Lokal

Unduh data aset terbaru dari database cloud Supabase ke penyimpanan lokal browser ini.

Panduan Setup Supabase (3 Langkah)

  1. Buat Akun / Project: Buka supabase.com, buat akun gratis dan klik New Project.
  2. Jalankan Skema SQL: Buka menu SQL Editor di Supabase, buat query baru, lalu tempel isi file schema.sql dan klik Run.
  3. Salin Kunci API: Buka Project Settings -> API, salin URL dan anon public key ke form di samping.
